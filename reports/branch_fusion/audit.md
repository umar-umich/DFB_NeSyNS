## 3. B1 and the discount convention

- implementation: `analysis/tbiom/grouped/ops.py:discount`
- convention: **evidence_scaling**, `e'_k = r e_k`
- belief discounting would instead be: `b'_k = rho b_k, u' = 1 - rho + rho u; e'_k = rho u e_k / (1 - rho + rho u)`
- these are **not** equivalent operators

## 13. Corrections to inherited notes

- **Shared features do not imply fusion cannot help.** Distinct heads over one representation can preserve different predictive information, and a fused score can beat both. What the previous campaign showed is narrower: `legacy_om` is a deterministic function of the appearance feature through a 32-dimensional bottleneck, so it adds no INFORMATION at eval -- that is a statement about this particular construction, not about shared trunks in general.
- **LayerNorm adaptation changes activations and can change attention.** Rescaling a block's activations alters the pre-softmax logits downstream, so the claim that LayerNorm leaves the attention function intact is wrong as stated. The defensible version is that it does not add parameters to the projections and keeps the trunk's weight matrices fixed.
- **LoRA does not force the original pretraining objective.** The adapter is trained on the detection loss; calling it 'further along the contrastive objective' overstates what is known. What is measured is that LoRA buys standalone AUROC and LayerNorm-only buys fused AUROC.
- **Different recipes do not guarantee independent errors.** Using distinct adaptation knobs per branch is a reason to EXPECT less correlation, not evidence of it. Error correlation is measured per subset and reported, never assumed from the configuration.
- **Orthogonality is not causal identification.** The orthogonal residual construction and any subspace projection are geometric operations. No causal claim follows from them, nor from an attribution map or a shuffled sequence.
