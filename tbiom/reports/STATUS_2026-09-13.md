## 1. The frozen detector (R0)

Three views, Dempster–Shafer fusion, per-branch EDL auxiliary loss, trained on FF++ c23.

| view | what it is |
|---|---|
| Appearance | CLIP ViT-L/14 + LoRA feature |
| Off-manifold residual | β-VAE manifold residual (f_s − f_c) from the same CLIP trunk |
| Bona-fide face prior | frozen FS-VFM encoder + LoRA preservation student |

| | mean OOD AUROC | mean FPR_real |
|---|---:|---:|
| P0-DS baseline (2 views) | 0.8633 | 0.247 |
| **R0, 3 seeds** | **0.8782 ± 0.0012** | **0.135** |

Per dataset (3-seed mean): CDFv2 0.9505 (−0.014 vs baseline), CDFv3 0.9008 (+0.060),
DFD 0.9486, DFDC 0.8816, DFDCP 0.9002 (+0.043), DFEval24 0.6875 (limitation).
The gain is two wins, one loss, three ties; the real-side FPR drop is uniform on all six.

Other configurations: arm C 2-view (external fine-tuned Branch 3, semantic dropped) 0.8837 over
3 seeds but 4.5× the seed variance; not separable from R0.

**Run1-D (CE) caveat.** Reports show 0.8639, computed with a DS replay that is invalid for CE
outputs. On its native softmax it is **0.8689**, so the honest EDL−CE gap is **+0.0079 on one
seed**. `concat_ce` baseline implemented but never trained. EDL-vs-CE is thin.

## 3. Symbolic explanation overlay (post-hoc, not in the decision)

- Faithful: intervention survival **0.928**, agreement 0.990, coverage 0.821 (0.841 pooled),
  2,251 driver claims.
- Coverage gain came mostly from relaxing the "decisive" threshold (+0.215), not the added
  real-side rule (+0.025).
- Explains easy cases; the 2,478 unexplained videos hold **26% of all detector errors**.
- Every attempt to put symbolic structure in the decision path has not paid: selective gate ties
  trivial gates at its operating point; coherence training loss learned in-domain but did not
  transfer (−0.0081 AUROC).

## 5. SBI / FreqBlender brief (`docs/TBIOM_ClaudeCode_SBI_FreqBlender_Instructions.md`)

**Setup done.** FreqBlender source audited at the pinned revision; every paper-vs-code claim in
the brief verified; the repo has **no LICENSE file**. On-the-fly SBI integrated into the training
loader (fresh blend every epoch); all pre-run checks pass. 33 of 23,039 train frames lack
81-point landmarks, so all arms use one common eligible pool. Official FPNet and teacher weights
are behind a Baidu login and were not obtained; a split-safe authenticity teacher was trained
locally (val AUROC 0.9723, class order verified).

**Results, seed 42.**

| arm | recipe | AUROC | FPR_real |
|---|---|---:|---:|
| R0 | historical | 0.8768 | 0.212 |
| A | same recipe via new loader | 0.8667 | 0.184 |
| B | A + JPEG/resize exposure | 0.8669 | 0.094 |
| C | B + SBI replacing 50% of fake slots | 0.8138 | 0.098 |

| comparison | ΔAUROC | ΔFPR_real |
|---|---:|---:|
| A − R0 (loader only) | −0.0101 | −0.028 |
| B − A (processing) | +0.0002 | −0.090 |
| C − B (SBI) | **−0.0531** | +0.003 |

- **A − R0 is outside the seed band:** the new loader changes results by itself. Compare to A.
- **SBI hurts, via CDFv3:** 0.8728 → 0.6272. DFEval24 is the only set C improves (0.7085).
- **Processing exposure:** AUROC flat, FPR_real halved. Caveat: B's *baseline* TPR at τ is also
  lower (CDFv2 0.597 vs A 0.788), so part of the FPR drop is an operating-point shift.

Per-arm processing test (held-out jpeg q40 / resize 0.60):

| arm | ΔFPR_real | ΔTPR |
|---|---:|---:|
| R0 | −0.065 | −0.207 |
| A | −0.045 | −0.196 |
| **B** | +0.032 | **−0.031** |
| C | −0.130 | **−0.493** |

B is the only arm whose sensitivity holds under unseen processing. C reads FPR 0.000 at jpeg q40
on CDFv2 but TPR is 0.044 — it has stopped detecting fakes.

**SBI-D (FreqBlender) — not run.** Recipe: C + FreqBlender on 20% of SBI fakes. Teacher ready;
FPNet not yet trained; frequency-blend sanity checks not yet run. As specified it sits on C, the
losing arm.

## 7. Open decisions

1. **Confirm arm B** on seeds 1337 and 7 (~10h GPU). Everything downstream depends on it.
2. **SBI-D:** run as specified on C, or a deviation D′ = B + SBI at 10–20% + FreqBlender.
3. **SBI fraction:** is 50% simply too high? A 10–20% sweep would test that.
4. **Why A ≠ R0:** loader-induced −0.010 needs a cause before the writeup.
5. **Stage 3:** freeze the winner, re-export Stage 1, refit Stage 2 curves, then M1/M2/M3.
6. **Paper framing:** EDL-vs-CE is thin (+0.008, one seed); reenactment blindness and DFEval24
   are the clear limitations; the reliability/processing findings are the strongest material.
7. **Measurement gaps** the diagnostics point to: no temporal view (reenactment), partial
   manipulation, real-face temporal prior (e.g. V-JEPA on real faces).
