# Experiment 3b — temporal panel on stored frames

Frozen X-CLIP, TimeSformer, VideoMAE and V-JEPA 2 video features and frame-to-frame consistency features (ArcFace identity drift, landmark motion), all from the stored face crops (<= 32 frames per video, ~0.25–0.6 s apart; no raw videos exist for most test sets). Every family gets the same evidential probe on FF++ train, development-rule epoch selection, an ORDERED and a SHUFFLED-frame version, and fusion with the development-selected warm+gate views fitted only on the audit's grouped fitting folds. `spatial` = plain CLIP ViT-B/16 frame mean. Test sets are read afterwards. Script `analysis/tbiom/temporal/panel_probe.py`.

APP = Appearance, OM = Off-manifold residual, FP = Bona-fide face prior (raw); DS = equal Dempster–Shafer; LR = logistic stacking on matched inputs (p, vacuity). `<family>:ordered` vs `<family>:shuffled`: if they tie, the family adds appearance information, not temporal order.
